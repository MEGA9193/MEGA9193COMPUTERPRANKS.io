# 👾 Bilgisayar Trolleri (Computer Trolls)

Hoş geldiniz! Bu depo (repository), bilgisayar şakaları, eğlenceli troller ve zararsız "sinir bozucu" scriptler içermektedir. Arkadaşlarınıza ufak çaplı, zararsız şakalar yapmak veya sadece eğlenmek için kullanabileceğiniz kod parçacıklarını burada bulabilirsiniz.

## 🚀 Hızlı Başlangıç (Quick Start)

Projeyi kendi bilgisayarınıza klonlamak için aşağıdaki adımları izleyin:

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/MEGA9193/MEGA9193COMPUTERPRANKS.io.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd MEGA9193COMPUTERPRANKS.io
   ```
3. İlgilendiğiniz trol klasörüne girip `README.md` dosyasındaki veya yorum satırlarındaki talimatları okuyun.

## 🤝 Katkıda Bulunma (Contributing)

Yeni ve yaratıcı bir trol fikriniz mi var? PR (Pull Request) göndererek bu depoya katkıda bulunabilirsiniz. Lütfen eklediğiniz kodların donanımsal veya yazılımsal kalıcı bir hasar vermediğinden kesinlikle emin olun!

1. Bu repoyu fork'layın.
2. Yeni bir dal (branch) oluşturun: `git checkout -b yeni-trol-fikri`
3. Değişikliklerinizi commit edin: `git commit -m 'Eklendi: Ekranı ters çeviren şaka'`
4. Dalınızı push'layın: `git push origin yeni-trol-fikri`
5. Bir Pull Request açın.
